# Geocutters

Find mobile hairdressers near you.

## Setup

```bash
cd geocutters
npm install
```

## Run Locally

**Terminal 1 - API:**
```bash
cd apps/api
npm run dev
```

**Terminal 2 - Frontend:**
```bash
cd apps/web
npm run dev
```

## Access

- Frontend: http://localhost:3000
- API: http://localhost:3001
